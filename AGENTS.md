# Agent Guidance

This repository's memory bank is in [`memory-bank/`](memory-bank/). It preserves implementation history, helps contributors find project files, and collects lessons and implementation references for students.

Before making a substantial change, read:

- [`memory-bank/progress.md`](memory-bank/progress.md) for the latest project status and decisions.
- [`memory-bank/project-structure.md`](memory-bank/project-structure.md) to locate the owning area.
- Relevant entries in [`memory-bank/lessons/`](memory-bank/lessons/) for prior implementation examples.

The rules for maintaining and using the memory bank are in [`.agent/memory-bank-rules.md`](.agent/memory-bank-rules.md). Follow those rules when updating its contents. Repository and directory READMEs remain the source of truth for implementation conventions; the memory bank supplements them and does not replace them.

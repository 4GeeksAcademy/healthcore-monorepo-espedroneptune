# Lessons and Implementation References

This directory collects reusable lessons from HealthCore project implementations for students to study. Add a lesson when a milestone or implementation produces a concrete approach, useful tradeoff, or verification example.

## Organization

- Group lessons by project or milestone as the collection grows.
- Give each lesson a descriptive title and explain the problem, approach, key files, checks performed, and tradeoffs.
- Link to source files and tests in the repository instead of duplicating large code samples.
- Clearly identify examples that are incomplete, illustrative, or not production-ready.
- Do not include credentials, patient-identifying information, or other sensitive data.
